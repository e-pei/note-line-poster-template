note-line-poster / 初回セットアップ

ゼロから通しで
組み上げる手順

新しいメールアドレスを1つ用意して、LINE公式アカウントから note への自動投稿が 動きだすところまで。この手順で作る環境は、使う人ひとり専用です。 チェックを付けながら進めてください。途中で閉じても、次に開いたときに続きから再開できます。

所要 約 60 分
費用 初期 0 円
用意するもの パソコンの Chrome とスマホの LINE
手でやる

アカウントを作る・本人としてログインする・鍵を発行する。この3つには、どのサービスも API を用意していません。意図的に閉じている部分なので、迂回しません。

コマンドがやる

黒枠の中の文字をコピーして、ターミナルという画面に貼り付けて Enter を押す、という意味です。打ち込む必要はありません。ターミナルの開き方は「パソコンの準備」にあります。

まず、あなたはどれですか

この手順書は 「初めて1つ作る人」に向けて書いてあります。 上から順にやれば終わります。ただし、次の場合だけ追加でやることがあります。

あなたの場面この手順書の使い方
A. 初めて1つ作る
（お客さまに渡す1台目）		 上から全部やる。追加作業はありません
B. 同じパソコンで
2つ目以降を作る		 全部やる。ただし2か所だけ違います
① 準備：既存のフォルダを使い回さず、コピーを作ってから始める
② 04：wrangler login ではなく 名前付きログインを使う（既存のログインが消えるため）

いま動いている環境のフォルダで作業すると、接続先が新しいほうに書き換わって、元の環境が動かなくなります。 必ずフォルダごとコピーしてから始めてください。

つまずいたら

症状原因と対処
デプロイで You need to register a workers.dev subdomain Cloudflare で自分用のアドレスを登録していません。ダッシュボード → コンピュート → Workers とページ →「サブドメイン」の変更で登録し、 npm run setup をやり直す
疎通テスト COULD_NOT_CONNECT ／「Worker に接続できませんでした」 アドレス登録の直後は行き渡るまで数分かかります。2〜3分おいて npm run setup をやり直す。 それでも駄目なら、ブラウザで https://あなたのURL/ を開いて表示されるか確認
拡張が「サーバーに接続できませんでした」 接続先が違います。拡張の 「▼ 接続先の設定」→ サーバーのURL に 正しい URL を貼って「保存する」。例文のまま埋め込まれているのが原因のことが多いです
Couldn't find a D1 DB with the name or binding wrangler.jsonc の database_name / database_id が 04 で作ったものと合っていません。npx wrangler d1 list で正しい値を確認して貼り直す
作ったはずのデータベースが見つからない 別の Cloudflare アカウントに作られています。プロジェクトのフォルダで npx wrangler whoami を実行し、意図したアカウントか確認してください
npm install で EACCES / permission denied と出る 過去に sudo npm を使ったせいで、npm の作業用フォルダが管理者のものになっています。 sudo chown -R $(id -u):$(id -g) ~/.npm を実行し、パソコンのパスワードを入れてください（1回で直ります）
npm や node が見つからない、と出る Node.js を入れたあとターミナルを開き直していません。一度閉じて開き直してください
「そのようなファイルはありません」と出る ターミナルがプロジェクトのフォルダにいません。「パソコンの準備」の3つめをやり直してください
送っても何も返ってこない 応答設定の Webhook がオフ。01 の応答設定を見直してください
定型文と AI の返信が両方来る 応答メッセージがオン。オフにしてください
メニューが出ない トークを一度閉じて開き直す。それでも出なければ npm run setup:line
連携コードが違うと言われる 15分で切れます。LINE でもう一度「note連携」と送って新しいコードで
メール認証が完了していません note の確認メールを開いていません。02 に戻ってください
公開を押したのに投稿されない note のログインが切れている可能性があります。LINE で「連携状況」を確認してください
拡張のアイコンに「!」が出る 連携が切れています。LINE で「note連携」からやり直してください
いまの状態を知りたい LINE で「連携状況」。技術的には /health を開くと全項目が見えます

結局、人の手が要るのは5つだけ

LINE公式アカウントの開設、鍵の貼り付け、応答メッセージのオフ、Claude のキー発行、 そして note へのログイン。このうち4つは初回だけで、日常的に発生するのは 最後の1つ（月1回ほどのつなぎ直し）だけです。それも3手で終わります。

残りは全部 npm run setup がやります。どのサービスも「アカウントを作る」「本人としてログインする」 「鍵を発行する」の3つには API を用意していません。意図的にそうしている部分なので、迂回はしません。
